# WSFI API (for developers)

Base URL: `https://xdbrtdcrhqabckirhssu.supabase.co/rest/v1/`
Header on every request: `apikey: sb_publishable_3M1mEDnK1mNPE6uicQrs_Q_QP5bhUqU` (read-only publishable key).

The API is generated by Supabase (PostgREST) from the database tables. All tables are read-only for this key; data is written only by the ingestion pipeline.

> Until real data arrives, observations come from runs marked `is_synthetic = true`. Real runs automatically take precedence in `observation_current`.

## Tables and views

| Endpoint | What it holds |
|---|---|
| `pillar` | The five pillars (A–E) plus X (supporting data), with their role in the index |
| `indicator` | One row per indicator code: unit, `higher_is` (`worse` / `better` / `context`), source, cadence |
| `spatial_unit` | Countries (`ADM0`, ISO3) and Sri Lanka districts (`ADM2`, `LK-xx`, `parent_id = LKA`) |
| `observation_current` | **Use this one.** Latest value per unit × indicator × year × scenario, with provenance |
| `observation` | Every value from every run, including superseded ones |
| `source_run` | One row per data pull: source, retrieval date, file hash, synthetic or not |
| `weight_set`, `weight` | Versioned weight sets (pillar and indicator level). `equal-v0` is the default |

## Example queries

```bash
KEY=sb_publishable_3M1mEDnK1mNPE6uicQrs_Q_QP5bhUqU
BASE=https://xdbrtdcrhqabckirhssu.supabase.co/rest/v1

# All indicators with their units and direction
curl "$BASE/indicator?select=code,name,unit,higher_is,pillar" -H "apikey: $KEY"

# Sri Lanka, everything current
curl "$BASE/observation_current?unit_id=eq.LKA" -H "apikey: $KEY"

# Projected water stress (A1), BAU 2050, all countries
curl "$BASE/observation_current?indicator_code=eq.A1&scenario=eq.bau&year=eq.2050&select=unit_id,unit_name,value" -H "apikey: $KEY"

# Sri Lanka districts for one indicator
curl "$BASE/observation_current?unit_level=eq.ADM2&indicator_code=eq.B1&select=unit_id,unit_name,value" -H "apikey: $KEY"

# Default weights
curl "$BASE/weight?select=level,code,weight,weight_set!inner(name)&weight_set.is_default=eq.true" -H "apikey: $KEY"
```

JavaScript: `createClient(url, key).from('observation_current').select('*').eq('unit_id','LKA')`.

## Things to know

- **Raw values, native units.** Nothing is normalised yet. Use `indicator.higher_is` to know which way is good.
- **Gaps are explicit.** Rows with `flag = missing` or `not_applicable` have an empty `value`; don't treat them as 0.
- **Scenarios:** `observed`, `baseline_1979-2019`, `optimistic`, `bau`, `pessimistic` (2030/2050/2080); `SSP2-4.5`, `SSP5-8.5` for sea level (2050/2100).
- **Pagination:** responses are capped at 1,000 rows. Use `limit` / `offset` or the `Range` header for larger pulls.
- **Index scores** (`compute_wsfi(...)`) will be added once the aggregation rules are agreed.
